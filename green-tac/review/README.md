# Green TAC review materials

Open `green_tac_prototype_review.pptx` in PowerPoint for the editable 12-slide
deck with native tables and speaker notes. It was rendered and visually checked
using the installed PowerPoint application.

Open `presentation.html` directly in Chrome or Edge. It works offline and has
12 slides, arrow-key navigation, speaker notes, fullscreen and browser printing.
Use N to toggle the current slide's notes. `speaker_notes.md` contains all notes.

Read `progress_report.md` in a Markdown viewer or open `progress_report.html`
in a browser for a printable report. The report is available in HTML/Markdown.

The HTML source is generated by `tools/build_review.py`. The PowerPoint
conversion uses the installed PowerPoint application and the local slide
layout, with the converter in `tools/export_review_powerpoint.ps1`.

The evidence is an initial prototype study, with poor held-out runtime-model
accuracy. Runtime measurements are empirical, while energy and carbon values
in the adaptive examples are proxies. Do not present them as measured savings.

From the repository root:

```powershell
python run.py demo
python run.py adaptive-demo
python tools/build_review.py
```
